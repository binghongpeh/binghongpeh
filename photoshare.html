❌ Upload failed

Most likely fix — set Firebase Storage rules:

1. Open Firebase Console → your project

2. Go to Storage → Rules

3. Replace the rules with:

rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /{allPaths=**} {
      allow read, write: if true;
    }
  }
}

4. Also go to Firestore → Rules and set:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

⚠️ These are open rules for a temporary sharing session. Do not store sensitive data.
